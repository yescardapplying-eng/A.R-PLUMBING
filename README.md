# A.R PLUMBING — Professional Plumbing Contractors

Reliable Plumbing Contractors in Chennai for Residential & Commercial Projects.

## 🚀 About A.R Plumbing
A.R Plumbing is a professional plumbing contracting firm based in Chennai, Tamil Nadu. We specialize in residential building plumbing, high-rise tower vertical piping, commercial IT park facilities, CPVC/UPVC water distribution lines, SWR drainage systems, and premium sanitaryware installations.

## 🛠️ Tech Stack
- **Framework:** Next.js 15 (App Router, SSG)
- **UI & Styling:** Tailwind CSS, Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript
- **Fonts:** Manrope (Headings) & Inter (Body)
- **Architecture:** Static Site Generation (38 pre-rendered routes)

## 💻 Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
